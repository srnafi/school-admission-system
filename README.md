# School Admission System

Online school admission, first come first served, with a time limited hold on each seat.

Backend: .NET 8, PostgreSQL, EF Core. Frontend: React, Vite, TypeScript. Everything runs
with `docker compose up` from this directory.

The project is in progress. Run instructions appear in this file as the pieces land.

| Path | Contents |
|---|---|
| `backend/` | ASP.NET Core API, EF Core migrations, xUnit tests |
| `frontend/` | React single page app, served by nginx |
